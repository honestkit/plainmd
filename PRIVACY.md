# MDGrab privacy policy
Last updated: 2026-09-29

MDGrab collects no personal data and makes no network requests. When you click the extension, it reads the page content
on the current tab so you can copy or download it as Markdown; that data stays in your browser (clipboard or a file you save).
No analytics, no ads, no remotely loaded code. Contact: via the "Support" tab on the Chrome Web Store listing.
